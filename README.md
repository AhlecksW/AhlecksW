# Cryo Chamber ❄️

Record mouse & keyboard macros, replay them on repeat, and trigger them from
images on your screen. A Windows desktop app.

## Download

**[⬇ Download Cryo Chamber for Windows](../../releases/latest)** — grab
**`cryochamber.exe`** from the latest release (or the **Releases** section in the
sidebar), then double-click to run. No Python or install needed.

> First launch may show a SmartScreen warning (it's an unsigned app) — click
> **More info → Run anyway**.

## Main features

- 🎥 **Record** mouse clicks, scrolls, and key presses, then replay them.
- 🔁 **Repeat** a set number of times or loop until you stop (press **F9**).
- 🖼 **Image recognition** — run a macro only when it sees an image on screen
  (80%+ similarity match).
- ⌨ **Global hotkeys** — start/stop any macro from anywhere.
- 🧊 **Routines** — chain macros with images: see image A → run macro 1, then
  see image B → run macro 2.
- 🔗 **Share** macros as copy-paste codes.
